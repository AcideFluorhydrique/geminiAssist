geminiAssist 是一個簡潔的 Gemini WebView 封裝應用程式，會阻擋所有非必要的網址

- 🔒 **注重隱私**：阻擋不必要的網址與追蹤
- 🎯 **專注介面**：純淨的聊天體驗，不受瀏覽器介面干擾
- 🔄 **切換阻擋模式**：可在受限與無限制模式之間自由切換
- 📱 **輕量化**：專注於核心功能的極簡應用程式

## 使用方式

- 點擊右上角的按鈕以開啟或關閉網址阻擋功能
- 如果登入時卡住（例如兩步驟驗證），請先關閉阻擋，登入完成後再重新開啟
- 向上滑動一點即可隱藏按鈕，在頁面頂端向下滑動則可重新顯示
- **拖曳**按鈕可將其移動至螢幕上的任何位置，系統會記住該位置
- 系統會記住目前的阻擋模式以及按鈕的隱藏狀態。全新安裝時預設為開啟阻擋
- 手機裝置會顯示 Gemini 的行動版版面，平板裝置則會顯示桌面版版面
- **長按**按鈕可重設對話。這將會清除 Cookie、快取與網站資料，並將您的帳號登出
